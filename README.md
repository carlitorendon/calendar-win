# calendar-win

A small, fast calendar widget for Windows 11, built in plain C++ with Win32, Direct2D, DirectWrite and the DWM acrylic backdrop.

It's a single native `.exe` of a few hundred KB, with no .NET, Electron, web view or installer, and nothing extra to ship.

## Features

- **Native Windows 11 look:** acrylic (frosted-glass) background, rounded corners, system shadow, Segoe UI Variable, your Windows accent color, and automatic light/dark mode.
- **Widget-style window:** no title bar, no resize, no maximize. Drag it by any empty area. It opens centered on the monitor your mouse is on.
- **Behaves like a flyout:** it has no taskbar or Alt+Tab entry and closes as soon as you click anywhere else. Launch it again to bring it back. If it's already open, launching it recenters it on today.
- **Week numbers** on the left: ISO 8601 when weeks start on Monday, otherwise the week containing January 1 is week 1.
- **Fiscal weeks** on the right, plus a fiscal year / quarter / period label in the header (see [Fiscal calendar](#fiscal-calendar)).
- **Go to any date** by typing it.
- **Copy a date** to the clipboard with one key.
- **Follows your Windows region settings** for month and day names, date order and (optionally) the first day of the week.
- **Sharp at any scale:** per-monitor DPI aware.

## Keyboard and mouse

| Key | Action |
|---|---|
| `Page Down` / `Page Up` | Next / previous month |
| `←` `→` `↑` `↓` | Move the selected day (one day / one week) |
| `Home` or `T` | Back to today |
| `G` | Go to a date |
| `Enter` | Copy the selected day (or today), without the year |
| `S` | Settings |
| `Esc` | Close the go-to box or settings, otherwise close the widget |

- The mouse wheel and the header chevrons change months.
- Clicking a day selects it.
- The footer hints and today's date are clickable.

When you change months with `Page Up`/`Page Down`, the selected day carries over to the new month. If that month is shorter, it uses the last day instead.

### Go to date (`G`)

| Input | Goes to |
|---|---|
| `5/28` | May 28 of the year currently shown |
| `5/28/2027`, `5/28/27` | May 28, 2027 |
| `5/2027` | May 2027 |
| `2027` | The same month in 2027 |
| `may`, `may 28`, `dec 2027`, `28 may 2027` | Month names work too |
| `today` | Today |
| `FW12` | Fiscal week 12 of the fiscal year currently shown (selects that week's Monday) |
| `FW12 2027`, `FW12/27` | Fiscal week 12 of FY2027 |

The order of numeric dates (M/D, D/M or Y/M/D) follows your Windows short-date setting.

## Settings

Press `S` or click **Settings** in the footer. Changes apply immediately and are saved to `%APPDATA%\CalendarWin\settings.ini`. You can also edit that file by hand:

```ini
[Calendar]
WeekStart=monday          ; auto | sunday | monday  (auto = Windows region setting)
ShowWeekNumbers=true
ShowFiscalWeeks=true
ShowFiscalPeriod=true
```

## Fiscal calendar

The fiscal column uses a common retail **52/53-week calendar**:

- The fiscal year ends on the **Sunday nearest January 31**, and the next one starts the following Monday.
- Fiscal weeks run **Monday to Sunday**. For fiscal week numbers to line up with the rows, keep the week start set to Monday.
- A fiscal year is named after the calendar year it starts in. For example, FY2026 runs from Feb 2, 2026 to Jan 31, 2027.
- Periods follow a **4-4-5** pattern per quarter. In 53-week years, the extra week joins period 12.

The header label (e.g. `FY26 · Q4 · P10`) describes the fiscal period the middle of the displayed month falls in.

## Requirements

- Windows 11 (the acrylic backdrop needs Windows 11 22H2 or later).
- To build: Visual Studio 2022 (Community is fine) with the **Desktop development with C++** workload.

## Building

```bat
build.cmd
```

The script finds Visual Studio with `vswhere`, compiles the icon resource and `src\calendar.cpp`, and produces `build\Calendar.exe`. The C runtime is linked statically, so the exe has no runtime dependencies.

The app icon (`assets\calendar.ico`) is generated by `tools\make-icon.ps1`. Rerun it with PowerShell 7 (`pwsh -File tools\make-icon.ps1`) after changing the design.

## Tips

- Pin `Calendar.exe` to the Start menu (or the taskbar as a launcher), or start it from your favorite launcher. Running it while it's already open just re-summons it.
- To assign a global hotkey, create a shortcut to `Calendar.exe` and set **Shortcut key** in its properties.
